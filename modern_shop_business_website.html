Choose Free Hosting Platform:

Option 1: Netlify (সবচেয়ে সহজ - ১ মিনিট সময় লাগবে) Recommended
  1. Netlify.com ওয়েবসাইটে গিয়ে একটি ফ্রি একাউন্ট তৈরি করুন।
  2. index.html এবং আপনার লোগো ছবি দুইটি একটি ফোল্ডারে রেখে সম্পূর্ণ ফোল্ডারটি জিপ (ZIP) করুন।
  3. Netlify Dashboard এর "Sites" ট্যাবে গিয়ে Drag and Drop করে জিপ ফাইলটি ছেড়ে দিন।
  4. কয়েক সেকেন্ডের মধ্যে আপনার ফ্রি ওয়েবসাইট লিংক পেয়ে যাবেন (যেমন: toponeglass.netlify.app)।
Option 2: GitHub Pages (ফ্রি প্রফেশনাল হোস্টিং)
  1. GitHub.com এ গিয়ে সাইন আপ করুন।
  2. নতুন একটি Repository তৈরি করুন (নাম দিন: top-one-glass-design)।
  3. আপনার index.html এবং লোগো পিকচার আপলোড করুন।
  4. Repository Settings > Pages এ যান এবং Source হিসাবে main branch নির্বাচন করে Save দিন।
